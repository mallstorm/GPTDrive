# GPT Drive 0.5.1

- Full sync no longer hangs forever when ChatGPT redirects `/library` to another internal route.
- Each phase has a hard time budget and advances even if a route marker changes.
- Structured ChatGPT file IDs are stored as stable `/backend-api/files/{file_id}/content` references.
- Expiring `oaiusercontent` signed URLs are removed from the index instead of being treated as durable files.
- Image previews, Android DocumentsProvider streams and downloads use authenticated account cookies and stable file resolution.
- API replay and autoscroll work are bounded to reduce sync time.
